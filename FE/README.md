# MyWorkspace 프론트엔드

파스텔 블루 기반의 React·TypeScript·Vite 앱입니다. 메인, 캘린더, 서버 대시보드, WOL과 로그인 화면을 제공합니다.

## 실행

Node.js 22.x를 사용합니다.

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run lint
npm run build
```

기본 모드는 실제 API를 사용합니다. 백엔드 없이 화면을 확인하려면 `VITE_API_MODE=mock npm run dev`를 사용합니다. 시안 API는 실제 인증이나 장치 제어를 수행하지 않습니다.

## 캘린더

개인·iCloud 일정은 학교 수업보다 먼저 표시하고 공휴일은 항상 표시합니다. 날짜 칸을 누르면 해당 날짜를 선택하고, 상세 목록에서 일정을 수정합니다. 추가·수정은 같은 모달을 사용하며 종일 여부를 전환합니다. 시작·종료 분은 5분 간격으로 선택하고 기존 비정규 시각은 보존합니다.

시간표는 한 과목에 여러 요일 또는 같은 날의 분리된 시간을 추가할 수 있습니다. 과목명·교수명은 공유하고, 휴강일과 추가 시간의 강의실은 시간별로 관리합니다. 같은 과목명·교수명·강의실의 기존 수업은 설정 초안에서 묶어 표시하며 저장 시 적용합니다. 시간 겹침을 거부하고 저장 실패 시 입력을 유지합니다.

## 암호 설정

왼쪽 아래 톱니바퀴에서 비밀번호 변경과 Google OTP 등록·해제를 합니다. 기존 비밀번호 또는 등록한 OTP를 선택해 확인합니다. OTP 최초 등록은 기존 비밀번호 확인과 앱의 첫 코드 확인을 모두 거칩니다. 암호 설정은 HTTPS에서 진행합니다.

## 기타 화면

메인은 서울 시간 기준 날짜·12시간제 시계·초와 날짜별 일정을 표시합니다. 서버 대시보드는 호스트·게스트의 자원 그래프를 표시하고 기간을 각각 선택합니다. WOL은 PC 목록을 편집하고 패킷 전송 결과와 시각을 표시하며 10초 재요청 제한을 적용합니다. 부팅 상태는 확인하지 않습니다. 모바일은 왼쪽 메뉴 패널과 화면 너비에 맞춘 모달을 사용합니다.

메인의 미니 달력은 학교 시간표를 일정 점 표시에서 제외합니다. 수업은 날짜별 목록에 계속 표시하며, 공휴일 숫자는 일요일과 같은 빨간색으로 표시합니다. 오늘·선택한 날짜·토요일인 공휴일도 빨간색을 유지합니다.

스토리지는 `local-lvm → local(있을 때) → 나머지 이름 오름차순`으로 표시합니다. 숫자는 `disk2 → disk10`처럼 정렬하며 서버의 응답 순서나 사용량이 달라져도 표시 순서를 유지합니다.

API 계약은 [client.ts](src/api/client.ts), 화면 검증은 [design-qa.md](design-qa.md)를 참고하세요.

## 이전 시안 데이터 정리

기존 데이터 가져오기 메뉴와 기능은 제거했습니다. 페이지를 열면 이전 시안의 브라우저 저장 데이터와 가져오기 완료 표시만 삭제합니다. 현재 서버 자료와 다른 브라우저 설정은 유지합니다. 브라우저 저장소는 주소별로 분리되므로 사용하던 각 주소에서 새 페이지를 열어야 정리됩니다.
