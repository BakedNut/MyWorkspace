## 필수 시각 요소

- 글꼴: 한글 시스템 글꼴과 읽기 쉬운 본문 크기, 큰 시계의 위계를 유지했다. 생성 이미지와 동일한 글꼴 파일을 특정할 수 없어 시스템 글꼴을 사용한다.
- 간격과 배치: 왼쪽 메뉴·시계·오늘 일정·오른쪽 달력 구성을 유지했다. 실제 본문 크기와 모바일 세로 배치에 맞춰 여백을 조정했다.
- 색상: 파스텔 블루 사이드바, 짙은 남색 글자와 의미별 일정 색상을 사용한다. 단색·가는 구분선 중심으로 구성했다.
- 이미지와 아이콘: 원본에는 별도 사진·일러스트 자산이 없다. UI 아이콘은 라이브러리의 벡터 아이콘을 사용한다.
- 문구: MyWorkspace 명칭과 한국어 메뉴를 적용했다. 지난 일정, 다음 일정, 샘플 데이터 여부를 글자로도 구분한다.
- 전체 비교와 원본 크기 데스크톱·모바일 캡처에서 주요 글자와 아이콘을 직접 확인할 수 있어 별도 확대 비교는 필요하지 않았다.
