- [P2, 수정 완료] 스크롤된 모바일 폼에서 검증 오류가 위로 사라질 수 있었다. 오류를 스크롤 영역 밖에 표시해 저장 실패 시에도 입력과 메시지를 유지한다.
- 검증: 빈 칸 추가, 블록 선택, 교수명·강의실·분 단위 시간 저장, 새로고침 유지, 중복 시간 거부, 삭제·취소, 저장 실패 입력 보존, 모바일 내부 스크롤·편집 저장. 페이지 실행 오류 0건. 자동 테스트 26개와 타입 검사·빌드가 통과했다. 린트 오류는 없고 기존 Fast Refresh 경고 2개가 있다.
- 남은 P3: 아주 짧은 수업과 작은 화면에서는 블록 문구를 생략할 수 있다. 수업 선택 목록과 상세 입력으로 전체 정보를 확인할 수 있다. 실제 서버 DB 저장은 기존 시안과 마찬가지로 아직 연결하지 않았다.
