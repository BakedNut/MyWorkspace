# 화면 설계

## 검토 대상

- 선택 시안: 첫 번째 이미지, Quiet Day.
- 서비스 표기: MyWorkspace.
- [Lovable 검토 프로젝트](https://lovable.dev/projects/2ce9597e-59a1-4aa7-b6a9-25795b4556b2)

## 유지할 방향

- 파스텔 블루 왼쪽 메뉴와 밝은 화면, 짙은 남색 글자.
- 메인은 날짜 아래 오전·오후 12시간 시계, 오늘 일정 타임라인, 오른쪽 미니 달력과 선택 날짜의 일정.
- 메뉴는 메인, 캘린더, 서버 대시보드, WOL. 로그인은 비밀번호 입력 한 개.
- 서버 CPU·RAM은 기간 선택 선 그래프, VM·LXC는 최대 3열의 1일 그래프 카드로 표시한다. 스토리지는 사용률 바를 유지한다.
- WOL은 최대 2열의 큰 깨우기 버튼을 표시하고 별도 모달에서 이름·MAC과 목록을 편집한다.
- 모바일은 왼쪽 고정 메뉴 패널과 한 열 카드 배치. 일정 모달의 시간 입력은 세로로 배치한다.

## 실제 서비스와의 경계

- 현재 디자인 시안의 일정·서버 정보·WOL은 샘플 데이터다.
- 실제 인증은 Spring Security, 영속 데이터는 MySQL에서 처리한다.
- iCloud와 Proxmox의 비밀정보는 프론트엔드나 Lovable에 전달하지 않는다.
- WOL의 기본 대상은 내 PC·형 PC이며 목록 수정 모달에서 PC 추가·삭제·이름·MAC 수정을 할 수 있다.
- 연동 전에는 실제 동기화나 패킷 전송을 완료했다고 표시하지 않는다.

## 검토 결과

- 큰 시계·오늘 일정·미니 달력의 구성을 유지했다.
- 지난 일정과 진행 중 일정을 글자로 구분하고 모바일 메뉴, 키보드 조작과 모달 포커스를 보완했다. 시계 아래의 다음 일정 요약은 제거했다.
- 수정한 정적 React 앱의 기준 소스는 GitHub의 `FE/`다. Lovable 프로젝트에 로컬 수정이 자동으로 반영되지는 않는다.
